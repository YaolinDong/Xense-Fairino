# 双臂安装参数来源与适用范围

本目录模型与项目 [整机 URDF](../../../../models/whole_body_20261030.urdf) 保持相同原文。
本目录的 URDF 是厂家 RD53 20261030 版原文，SHA-256：
`96d4b4fb6e6a584bc55e1e9f1cf538ff9b02cc2093f1cda1cc983cd48199be9c`。
没有复制 STL、控制器 YAML 或启动文件，本目录用于运动学计算，不能直接作为
完整 RViz 显示包。源文件来自厂家，没有为修正头腰编号或限位而编辑它。

## 型号核对

现有 TCP 控制程序使用 `ART7-R7-20260615-flange-x-106mm-v2` 模型，
来源是旧资料中的 `RD53-ART7-R7-双臂URDF和模型-v1.0-20260615` 和 ART7 DH。
核心尺寸 d1=187 mm、d3=290 mm、d5=310 mm，七个转动关节，法兰中心
相对最后一个腕心坐标偏移 `[-106,0,0] mm`。新整机 URDF 的两臂链与这些参数一致，
末轴的微小轴偏量与角度截断由独立 FK 审计量化。

新 `RD40-人形机械臂ART7-R7配置及使用用户手册-V1.0-20260727.pdf` 也标明
ART7-R7。早期混在资料中的 ART3-R7 手册与 SDK 3.0.0 头文件的 ART3 型号枚举，
不是当前控制程序的模型选择依据。本程序调用的是接受显式 DH 参数的厂家纯
运动学库，没有通过旧 `SingleRobot(ART3_...)` 类初始化机械臂。

这确认的是软件模型与厂家新资料匹配；没有通过这些文件证明实机铭牌、序列号、
扭矩传感器配置或安装误差。2026-10-08 初次只读访问上半身控制板时网络不可达，
恢复连接后已确认其配置 xacro 引用了 `fairino_description/urdf/art7.urdf`，
当前低层反馈为 J1–J20。板上同时保留多型号模板，其中部分动力学模板写有
`ART3_R7_JK20`；本次实际加载的只有状态广播和硬件命令控制器，没有加载这些
动力学控制器。因此不能把备用型号标签当作实机子型号，也不能据此直接启用拖动。

恢复连接后的只读反馈无关节故障，0/20 轴使能；当前实机关节姿态的厂家正逆解
及双臂共 24 个胸部方向目标均通过离线校验，未发送运动命令。
只读核对未发送运动指令；当前运行日志生成于项目 `.local/pico4/fairino-logs/`。

## 固定安装链

原始 `body_Link` 坐标下，xyz 单位 mm，rpy 单位 rad：

| 固定关节 | xyz | rpy |
|---|---|---|
| `left_arm_fixed_j1` | `[-48,+0.85882,329.61]` | `[-1.5708,0.7854,+1.5708]` |
| `right_arm_fixed_j1` | `[+48,-0.38815,330.86]` | `[1.5708,0.7854,+1.5708]` |

父 link 均为 `body_Link`。左右子 link 分别为 `left_arm_base_Link`、
`right_arm_base_Link`。URDF RPY 组合为 `Rz(yaw) Ry(pitch) Rx(roll)`。
运行时由 `mounts.py` 读取原始参数，两侧不共用或猜测同一个矩阵。

胸部坐标轴定义为 X 前、Y 左、Z 上，与原 body 的 +Y、−X、+Z 对应，原点
仍为 `body_Link`。首关节 j1/j8 相对 CAD 基座还有 XY 小偏置：
左 `[-0.88174,+0.33281] mm`，右 `[+0.88174,-0.33281] mm`。
这项平移加入一次后，厂家 DH 原点在胸部约为 `[0,±48,330] mm`。
187 mm 是 DH 中已有的首段长度，不再重复加入安装平移。

## 头腰与折叠关节

硬件与 URDF 的 J1–J20 同号同序。J15 转动头部，J16 转动腰部，J17 控制侧倾。工作台显示三轴反馈。双臂 IK 把头固定在模型零位，遥操指令保持头部和侧倾的实际关节值。

J18–J20 沿用身体程序的竖直标定。运动学使用 `j18 = J18 − upright_joint_sum`、`j19 = J19`、`j20 = J20`。校正量只作用于模型。Fairino QP 的求解模型和遥操接收端共用仓库迁移前（`b80f539`）的软件限位，按 RD53 编号和方向表示。模型角近似范围为 J16 ±172°、J17 ±28°、J18 ±60°、J19 0～130°、J20 −55～0°。J18 的编码器上下界需要分别加上当前标定的竖直角度和。精确弧度值见 [软件限位](../../../../apps/fairino_upper_probe/body_control/body_core.py)。身体程序另按标定限制前倾至 0～45°、侧倾至 ±15°、腰转至 ±90°，Fairino QP 遥操时保持侧倾。

手臂沿用 ART7 软件限位与已校准的 106 mm 法兰。腕部联合限位沿用已有标定，见 [腕部保护](../../../../docs/腕部保护.md)。
